# Linux and macOS experimental previews — gameplay unverified

Native Linux x64, macOS Intel x64 and macOS Apple Silicon arm64 setup kits for
Wipeout XL USA SCUS-94351. Each player supplies their own legally obtained disc;
no disc, retail BIOS, generated game code, memory cards or captures are included.

The same configurable NeGcon enhanced dual sticks and display mods are included.
See the [controller diagram](https://github.com/NJH-1001/Wipeout2K97XL/blob/main/docs/images/negcon-dual-sticks.png).

**Verification limit:** native build, dependency, emitter-startup and extracted
launcher-window checks pass in CI. Local game generation/rebuild, OpenBIOS
gameplay, controller hardware and rendering mods have not been verified on
Linux/macOS. These are experimental previews published with the project owner’s approval. The Windows release remains the gameplay-tested version.

Build provenance: [native CI run 34263238594](https://github.com/NJH-1001/Wipeout2K97XL/actions/runs/34263238594),
source `49c024a373e7bee20aa32df5caf60b1d9b8a3511`. The downloadable previews
retain those binaries unchanged; updated documentation and the user-provided
controller diagram are added after CI. Each ZIP has a SHA-256 checksum.

See [native platform instructions and verification gates](https://github.com/NJH-1001/Wipeout2K97XL/blob/main/docs/native-platforms.md).
